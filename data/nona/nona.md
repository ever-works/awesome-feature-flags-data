## Overview

Nona is an open-source remote configuration and feature flag service that exposes a single REST API. It supports multiple environments and provides official client libraries for JavaScript and .NET. The project is self-hostable using Docker and is distributed under the Apache-2.0 license.

## Features

- Single REST API for remote configuration and feature flags
- Multiple environment support
- Official JavaScript client SDK
- Official .NET client SDK
- Self-hosted deployment via Docker
- Apache-2.0 licensed open source

## Pricing

Free and open source under the Apache-2.0 license; self-hosted, so there are no managed SaaS fees.

## Deployment

Self-hosted (Docker).

## Integrations

- REST API
- JavaScript SDK
- .NET SDK
