## Overview

Hypertune is a configuration platform providing type-safe feature flags, A/B testing, analytics, and app configuration with Git-style version control. It enables teams to manage feature flags with strong type safety and version-controlled configuration.

## Features

- Type-safe feature flags
- A/B testing
- Analytics and insights
- App configuration
- Git-style version control
- Strongly-typed SDKs
- Managed platform
