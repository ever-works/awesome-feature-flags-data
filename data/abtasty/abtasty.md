## Overview

ABTasty is a customer experience optimization and feature management platform. It provides managed services for feature flags, A/B testing, personalization, and user experience optimization across web and mobile applications.

## Features

- Feature flag management
- A/B testing
- Personalization
- User experience optimization
- Web and mobile SDKs
- Analytics and reporting
- Managed cloud platform
