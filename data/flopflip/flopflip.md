## Overview

Flopflip is a feature management library for React applications written in TypeScript. It provides an abstraction layer over feature flag providers, enabling React apps to consume flags from any compatible source without being locked into a specific vendor.

## Features

- React feature flag integration
- Provider-agnostic architecture
- TypeScript support
- Multiple provider support
- Hook-based API
- Declarative components
