## Overview

Laravel Pennant is a simple, lightweight feature flag package for Laravel applications written in PHP. It provides feature toggle functionality natively integrated into the Laravel ecosystem.

## Features

- Feature flag management for Laravel
- Lightweight implementation
- PHP integration
- Database driver support
- Conditional blade directives
- Artisan commands for flag management

## Pricing

Free and open-source under the MIT license (part of Laravel ecosystem).
