## Overview

Abby is an open-source feature flag and A/B testing platform. It supports configuration as code and provides fully typed TypeScript SDKs.

## Key Features

- Feature flags for gradual rollouts
- A/B testing capabilities
- Configuration as Code
- Fully typed TypeScript SDKs
- Strong integration with Next.js and React
- Generous free tier
- Self-hostable

## Deployment

Self-hosted / Open-source

## Pricing

Open source with a generous free tier and cheap scaling options.
