## Overview

FeatureProbe is an open source feature management service. It is a visual "feature" management platform providing feature toggles, canary releases, and A/B testing functionality.

## Features

- Feature flags / toggles
- Canary releases (gray release)
- A/B testing
- Visual management interface
- Self-hosted deployment
- Multi-language SDKs

## Pricing

Open source, self-hosted. License details available in the project repository.

## Integrations

SDKs available for multiple programming languages.
