## Overview

Flipper is a feature flag library for Ruby applications. It enables Ruby on Rails and other Ruby applications to manage feature toggles and controls for both server-side and client-side code.

## Features

- Feature flag management for Ruby
- Ruby on Rails integration
- Client-side flag controls
- Multiple adapter support
- Dashboard UI
- Open-source (MIT license)

## Pricing

Open-source library (free); hosted cloud service available.
