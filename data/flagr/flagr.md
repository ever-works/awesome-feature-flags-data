## Overview

Flagr is an open-source feature flagging, A/B testing, and dynamic configuration microservice written in Go. It enables teams to manage feature flags and run experiments in a self-hosted environment.

## Features

- Feature flag management
- A/B testing capabilities
- Dynamic configuration
- Self-hosted deployment
- Go-based microservice
- REST API for integration
