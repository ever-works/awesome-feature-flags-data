## Overview

HappyKit is a feature flag solution designed specifically for Next.js applications. It enables Next.js developers to manage feature flags and control feature availability in both frontend and edge environments with TypeScript support.

## Features

- Next.js feature flag integration
- Edge runtime support
- TypeScript support
- Client and server-side flags
- Dynamic flag evaluation
- Next.js middleware support
