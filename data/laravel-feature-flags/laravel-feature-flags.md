## Overview

Laravel Feature Flags is a feature flag package for Laravel applications written in PHP. It provides Laravel developers with a simple way to manage feature toggles within their PHP applications.

## Features

- Feature flag management for Laravel
- PHP implementation
- Blade directives
- Middleware support
- Configuration-driven flags
- Database-backed flag storage

## Pricing

Free and open-source.
