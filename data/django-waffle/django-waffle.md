## Overview

Django Waffle is a feature flipper (feature flag) library for Django applications written in Python. It enables Django developers to dynamically enable or disable features, run A/B tests, and control feature availability based on user groups or other conditions.

## Features

- Feature flag toggles
- A/B testing support
- User and group targeting
- Django integration
- Middleware support
- Template tags and decorators
- Open-source (BSD license)
