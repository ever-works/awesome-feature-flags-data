## Overview

Unleash is a powerful open-source feature management solution that enables teams to roll out features safely, target specific users, and run gradual rollouts. It is self-hosted and offers official SDKs for multiple languages, including OpenFeature-compatible providers.

## Features

- Self-hosted feature flag management
- Advanced user targeting
- Gradual and phased rollouts
- OpenFeature SDK support
- Official client and server SDKs
- Audit trails and access control
- Feature strategies and constraints

## Pricing

Open-source (free to self-host); hosted plans available.
