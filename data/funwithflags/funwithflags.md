## Overview

FunWithFlags is an open-source feature flag library for Elixir applications. It enables Elixir and Phoenix developers to manage feature toggles, target specific users or segments, and control feature rollouts directly within their Elixir applications.

## Features

- Feature flag management for Elixir
- Phoenix integration
- User and segment targeting
- Dashboard UI for flag management
- Ecto backend support
- Open-source (MIT license)
